# JARVIS AI Assistant 🤖

## About the Project

JARVIS is my personal AI assistant project, developed using Python.

The goal is to build a voice-enabled assistant that can understand commands, respond naturally, and help with everyday computer tasks.

## Planned Features

- Voice recognition
- Spoken AI responses
- Local AI using Ollama
- Natural conversations
- Computer assistance
- Futuristic blue-and-black interface

## Technologies

- Python
- Ollama
- Speech recognition
- Text-to-speech
- PySide6 (GUI)
